## 📌 Project Description
A complete Smart Image Enhancement & Analysis System that takes a 
low-quality image as input and produces an enhanced, visually 
improved output with analytical insights.

---

## 🎯 Objectives
- Develop a complete image processing pipeline
- Apply theoretical concepts in a real-world scenario
- Perform image analysis and enhancement systematically

---

## 🛠️ Tools Used
- MATLAB

## ⚙️ How to Run
1. Clone this repository
2. Open MATLAB
3. Navigate to `code/` folder
4. Run `main.m`
5. Output images will be saved in `images/output/`
